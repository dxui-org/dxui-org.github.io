# 学习路线

会写 Go 就可以开始。先打开[第一个窗口](./getting-started)，复制完整代码，在本地运行 `go run .`。

## 入门：先学这三步

1. [运行窗口](./getting-started)：安装 DXUI，看到第一个桌面窗口。
2. [添加交互](./state)：点击按钮改变数字，输入文字并保存。
3. [排列界面](./layout)：把控件横排或竖排，让界面适应窗口大小。

## 接着做一个小应用

学习[样式与主题](./style)，调整颜色、间距和明暗主题；再完成[表单示例](./forms)，练习输入、校验和提交。

## 用到时再看

- 耗时任务：[后台任务](./async)。
- 打开更多窗口：[多窗口](./multi-window)。
- 遇到问题：[排错指南](./troubleshooting)。
- 找控件和示例：[组件参考](/zh-cn/components/)；查方法和参数：[API 索引](/zh-cn/api/)。
