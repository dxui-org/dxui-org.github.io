# Learning path

If you know Go, you are ready. Start with [your first window](./getting-started), copy the complete program, and run `go run .` locally.

## Start with these three steps

1. [Run a window](./getting-started): Install DXUI and open your first desktop window.
2. [Add interaction](./state): Change a number with a button and retain text input.
3. [Arrange the UI](./layout): Place controls horizontally or vertically and adapt to window size.

## Build a small application

Explore [styles and themes](./style) for colors, spacing, and light/dark appearance. Then complete the [form example](./forms) to practice input, validation, and submission.

- Expensive work: [Background tasks](./async).
